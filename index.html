氣象數據應用 · Bento Grid APP #01

🌤️ 台灣即時天氣觀測站

專案核心介紹： 本專案採用當代流行之 Bento Grid（便當盒風格）模組化介面設計，專為行動裝置打造流暢直覺的即時氣象探索體驗。系統整合全台主要觀測站數據，提供每小時即時氣溫、降雨機率預警、紫外線強度、體感溫差及空氣品質指標（AQI）。透過動態溫差趨勢圖與風速風向圖表，將繁瑣的數值氣象資料轉化為清晰易讀的圖形化視覺，協助使用者在快節奏生活中迅速掌握出行天氣變換與穿著建議。
運用的 API 與核心技術：
中央氣象署觀測資料 API Browser Geolocation API (定位) Chart.js HTML5 Canvas API Fetch / RESTful JSON API
應用場景 (Use Cases)：

每日上班族與學童通勤穿著決策、戶外賽事與露營行程即時降雨預警、智慧城市生活資訊看板，以及旅行者的在地隨身氣候助理。

商業數據決策 · BI Dashboard DATA #02

📊 鼎盛銷售經營診斷儀表板

專案核心介紹： 這是一套專為企業高階決策者與業務主管打造的商業診斷儀表板。系統內建超過 820 筆 B2B 擬真銷售訂單分析引擎，並支援使用者即時拖曳上傳外部 Excel 與 CSV 檔案進行即時分析。核心涵蓋 Pareto 虧損原因深度歸因、業務員折扣越權偵測、大客戶集中度營運風險評估及產品售後退貨成本損耗分析。透過多維度篩選器與動態視覺圖表，協助管理層迅速鎖定利潤侵蝕漏洞並制定精準修正決策。
運用的 API 與核心技術：
SheetJS / XLSX.js API (Excel 解析) Chart.js Multi-Axis / Bubble API HTML5 Drag and Drop API FileReader API (本機陣列串流)
應用場景 (Use Cases)：

企業每月董事會營運健檢、B2B 銷售通路毛利稽核、業務經理季度業績與折扣權限核定、產品線生命週期淘汰評估與財務風控。

沉浸體驗 · 塔羅心靈 APP #03

🌿 森語塔羅・心靈占卜

專案核心介紹： 森語塔羅是一款融合自然美學與深度心靈指引的互動式 Web 應用程式。介面採用深翠森林色調與磨砂玻璃光暈，內建完整的 78 張偉特塔羅牌（包含 22 張大阿爾克那與 56 張小阿爾克那），並具備正逆位雙向解讀資料庫。系統模擬真實物理洗牌動態，並透過流暢的 3D 卡牌翻轉動畫呈現儀式感。支援單張啟示、過去現在未來以及身心靈三角牌陣，占卜結果亦自動同步儲存於本機歷史紀錄，提供溫柔內省空間。
運用的 API 與核心技術：
Web Storage API (localStorage 紀錄存取) CSS 3D Transforms / Perspective Engine Dynamic DOM Shuffling & Transition API Web Vibration / Interaction Feedback
應用場景 (Use Cases)：

個人每日冥想晨間指引、面對人生轉折與工作瓶頸之自我對話引導、心理諮商破冰小工具，以及沉浸式數位休閒體驗。

打開 / 啟動占卜 (Launch Tarot)
組織架構 · 人資系統 SYS #04

🏢 部門階層架構與人員異動系統

專案核心介紹： 專為中大型企業設計的人力資源組織架構與人員調動平台。透過直觀的樹狀圖層級視覺化，即時呈現企業跨事業群、部門及團隊的從屬關係與各層級員額編制。系統支援組織階層靈活調整、員工職等薪級設定，並具備完整的人事調動指派流程與歷程稽核紀錄。讓 HR 與部門主管在進行組織重組、跨部門調遣或專案編組時，能以視覺化方式快速評估團隊負載與權責劃分，大幅提升跨部門協作效率。
運用的 API 與核心技術：
DOM Tree Traversal & Hierarchical API Event Delegation & Modal API JSON State Mutation & Filter Engine Custom Audit Log Tracker
應用場景 (Use Cases)：

企業併購後的部門整併、大型集團年度員額編制規劃 (Headcount Budgeting)、跨專案敏捷小組人員借調管理與企業內規稽核審查。
